# Asset provenance

Robot, Robotiq 2F-85 V4, and Psyonic Ability hand XMLs and referenced meshes
are copied byte-for-byte from SEW-Geometric-Teleop. See assets/provenance.json
for paths, source revision, and SHA256 hashes. The source repository license
is preserved as assets/SOURCE_LICENSE.txt; original upstream asset terms remain
applicable. Generated scenes only compose/namescope those descriptions and add
lighting, floor and a mocap base. No private solver source is distributed here.

XRT_devices and geo_kin_core retain their own licenses. geo_kin is a separately
licensed Rust wheel.
